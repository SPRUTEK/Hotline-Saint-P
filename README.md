# Hotline Saint-P

Установщик игры для Windows 10/11 (64-бит) с автообновлением.

**Скачать:** [последняя версия](https://github.com/SPRUTEK/hotline-saint-p/releases/latest) → файл `HotlineSaintP-Setup-….exe`.

Игра сама проверяет обновления при запуске и каждые 30 минут, скачивает их в фоне и предлагает перезапуститься. Сохранения лежат в `%APPDATA%\hotline-spb` и при обновлении не трогаются.

## Как выпустить обновление
1. Обновить файлы игры в `game/` (`./sync.sh` копирует их из папки проекта).
2. Поднять `version` в `package.json` (например 1.0.1 → 1.0.2).
3. Закоммитить и запушить в ветку `release` — GitHub Actions соберёт установщик и опубликует релиз, а установленные игры подтянут его сами.

F11 / Alt+Enter — полный экран.
